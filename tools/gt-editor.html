Callout Ground-Truth Editor — controls

Review and fix the callout boxes for each diagram, then mark the section Verified. Everything saves to groundtruth.json.

Box layers & colours

GT — ground truth (editable) Selected box Vision (reference) Tesseract (reference) OCR-flagged (re-OCR read a different number — labelled OCR:x)

Toggle each layer with the checkboxes in the toolbar. Vision & Tesseract boxes are read-only references — click one to copy it into GT (skipped if it overlaps a GT box of the same number).
