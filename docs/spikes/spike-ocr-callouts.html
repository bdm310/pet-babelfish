Spike 5 — OCR Callout Extraction

Tracks the PDF current transform matrix (CTM) through the operator list to find the exact position of the diagram image on the page, renders + crops to that region, then runs Tesseract.js (PSM 11, digits whitelist) to find callout numbers. Uses the fine-tuned porsche model via docs/spikes/tessdata/ (junction to training/). Serve from any directory containing this file: python -m http.server 8080, then open http://localhost:8080/spike-ocr-callouts.html.
