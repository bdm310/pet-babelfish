pet-babelfish

A browser-based tool for ingesting, searching, and browsing Porsche Electronic Toolbox (PET) parts catalogs. Everything runs locally in your browser — no server required.

Tools

  • Ingest a catalog
    Load a PET PDF → extracts parts + diagrams → stores in browser (OPFS)
  • Browse parts
    Search and browse ingested catalog — section tree, parts table, diagram view
  • Garage
    Save vehicles (VIN or manual) with their catalog + spec filter for one-click browsing
  • Raw table browser
    Inspect raw SQLite tables from an ingested catalog

Investigation Spikes

  • Spike 1 — Fetch behavior run first
    Tests whether catalog PDFs can be fetched directly from the browser (CORS check)
  • Spike 2 — PDF text structure
    Explores TOC/outline, page types, column layout, and part number formats
  • Spike 3 — Diagram callout extraction
    Checks whether diagram callout numbers are embedded PDF text (with coordinates) or image-only
  • Spike 4 — Applicability format
    Analyzes the vocabulary used in parts applicability data to determine if structured parsing is feasible
  • Spike 5 — OCR callout extraction in progress
    Extracts the embedded diagram image XObject directly from the PDF and runs Tesseract.js to locate callout numbers

Local development

WASM and OPFS require HTTP — open via a local server, not file://:

npx serve docs
# or
python -m http.server --directory docs 8080
